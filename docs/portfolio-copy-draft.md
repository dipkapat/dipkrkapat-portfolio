## 2. About

I started as a web designer in 2006 - pure HTML/CSS, Photoshop comps, the era before frameworks had names people remembered. Eighteen years and nine roles later, that same eye for layout, hierarchy, and detail now ships as production React and Next.js code.

The shift happened gradually and then all at once. Somewhere around 2020, "designing the screen" and "building the screen" stopped being two separate jobs on two separate desks. I started doing both - converting my own Figma files into pixel-perfect, responsive components, then wiring in the interactions myself with Tailwind and Framer Motion. Since then I've shipped 25+ production modules for a single enterprise ERP product, and I've leaned hard into AI-assisted workflows - Claude Code, Cursor, LLM plugins - not as a novelty, but as a genuine multiplier on design-to-code turnaround.

I don't design in isolation from implementation. If I hand you a screen, I can also hand you the component that renders it.

## 3. Featured Work - Flagship Case Study

### School Automation ERP - 25+ Modules, One Product, Six Years

**Adhyan Digital Pvt. Ltd. · Aug 2020 – Present**

_[Placeholder: 2–3 sanitized module screenshots or mockups go here - Attendance, Marksheet, and Student Analytics are probably your strongest visual candidates]_

**Challenge**
An in-house school automation platform needed to cover the full operational surface of a school - academics, attendance, fees, payroll, transport, library, hostel, admissions, and more - as a single coherent product, not a patchwork of disconnected tools. Every module had to feel like it belonged to the same system, at production quality, on a continuous delivery cycle.

**Solution**
I own the full design-to-code pipeline for the product: high-fidelity Figma designs, converted into fully responsive React components using React JS, Next.js, and Tailwind CSS. I built out Flowbite and Shadcn UI as a shared component foundation across the suite, so 25+ modules stay visually and structurally consistent without every screen being designed from scratch. Framer Motion carries the micro-interactions - the small transitions that make a dense admin product feel considered rather than utilitarian.

Modules shipped include: Announcement, Academic, Attendance, Users, e-Contents, Marksheet, Student Analytics, Lesson Planner, Calendar & Events, Routine, Assignment, Study Materials, Admission, Fees, Leave Management, Employee Management, Payroll, Transport, Library, Accounts, Hostel, Visitor, Teacher Feedback, Certificate Management, Promotion, ID Card, and Reports.

**Impact**

- 25+ production-ready modules shipped and maintained across a single unified product
- A consistent design system (Flowbite + Shadcn UI) carried across the entire suite, cutting redundant design and build work module over module
- Ongoing cross-browser debugging and stability work on a live, actively-used production system
- On-page SEO practices applied to improve discoverability where relevant

**AI Acceleration**
Claude Code and LLM plugins are part of my day-to-day workflow, not a side experiment - used to accelerate the translation of Figma designs into working components, speed up debugging cycles, and shorten the design-to-code loop across a large, multi-module codebase.

## 6. Process (optional section)

**From Figma to production, in four steps:**

1. **Design** - High-fidelity mockups and interactive prototypes in Figma, built around real stakeholder requirements.
2. **Scaffold** - AI-accelerated component scaffolding (Claude Code, LLM plugins) turns the design into a working starting point fast.
3. **Refine** - Hand-tuned Tailwind, Shadcn UI, and Framer Motion pass - the part that separates "AI-generated" from production-ready.
4. **Ship & Debug** - Cross-browser testing and live production debugging, module by module.
