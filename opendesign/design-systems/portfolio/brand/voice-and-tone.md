## Tone by Context

### Hero / First Impression

- **Tone:** Authoritative, concise, outcome-focused
- **Pattern:** `[Role] · [Role] · [Specialty]` + outcome statement
- **Avoid:** "I am a..." / "Welcome to my portfolio"

### Case Studies / Work

- **Tone:** Narrative, problem→solution, metrics where possible
- **Structure:** Challenge → Approach → Outcome
- **Voice:** "We reduced..." / "The system handles..." (not "I did...")

### About / Bio

- **Tone:** Personal but professional, chronological narrative
- **Pattern:** Origin → Evolution → Current focus
- **Key phrase:** "I started with websites. I ended up building products."

### Contact / CTAs

- **Tone:** Direct, low-friction, human
- **Primary:** "Let's Talk" / "Get in Touch"
- **Secondary:** "View Selected Work" / "View Case Study"

## Writing Rules

### Casing

- **Section titles:** Title Case ("Selected Work", "Design to Code")
- **Eyebrows:** Numbered + Title Case ("03 / Selected Work")
- **Buttons/CTAs:** Title Case ("View Case Study", "Let's Talk")
- **Labels (mono):** UPPERCASE ("UI/UX", "FRONTEND", "ROLE", "STACK")
- **Body copy:** Sentence case

### Punctuation

- **Oxford comma:** Yes
- **Em dash:** For emphasis and asides -like this
- **Ellipsis:** Only in quoted speech
- **Periods in buttons:** No
- **Periods in cards/labels:** No (unless full sentences)

### Numbers

- **Years:** "18+" not "eighteen"
- **Counts:** "25+" not "twenty-five plus"
- **Percentages:** "40%" not "forty percent"
- **Large numbers:** "1.2M" not "1,200,000"

### Emoji / Icons

- **Never** as decorative bullets or feature markers
- **Only** as inline UI affordances (arrows on links, external link indicators)
- **Lucide icons** for UI: ArrowRight, ArrowUpRight, Mail, etc.

### Contractions

- **Use freely** in body copy ("I've", "don't", "can't")
- **Avoid** in headlines and buttons

### Technical Terms

- **First use:** Spell out + abbreviate ("React Server Components (RSC)")
- **Subsequent:** Abbreviation OK
- **Stack lists:** "React · Next.js · TypeScript · Tailwind" (middle dots)

## Words to Use

- craft, precision, execution, production-ready, system, interface, product, workflow, bridge, intersection, clarity, intent

## Words to Avoid

- passionate, expert, guru, ninja, rockstar, cutting-edge, bleeding-edge, world-class, best-in-class, seamless, holistic, leverage, utilize (use "use"), facilitate (use "help"), implement (use "build")

## Microcopy Patterns

- **Empty states:** "No projects match this filter."
- **Loading:** "Loading case study…"
- **Error:** "Something went wrong. Try again."
- **Success:** "Message sent. I'll reply within 24 hours."
- **Form labels:** "Email address" (not "Your Email")
- **Placeholders:** "dip@example.com" (realistic example)
